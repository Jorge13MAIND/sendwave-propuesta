# Propuesta Sendwave Content Hub · Teckel AI

Landing de la propuesta comercial para Sendwave LatAm (16 de septiembre de 2026). HTML, CSS y JS sin framework; se despliega en Vercel como `sendwave-propuesta`.

- `index.html` · la propuesta (13 secciones). Los precios están como texto en la sección `#inversion`.
- `app.js` · verificador de guion en vivo de la portada (seis reglas de ejemplo, en el navegador) y calculadora de horas (`#roi`).
- `estilos.css` · identidad de Sendwave (amarillo sol, cacao, crema; Bricolage Grotesque + Figtree + JetBrains Mono).
- `assets/` · símbolo y wordmark de Sendwave, marca de Teckel, capturas del demo real.

El demo funcional vive aparte: repo `sendwave-demo`, https://sendwave-demo.vercel.app.
